Computer Vision · PyTorch · FastAPI

Automated Microbial Colony Detection & Classification

01

Designed and deployed a fully automated AI system to detect, count, and classify microbial colonies from petrifilm lab samples — replacing an entire team of manual lab analysts with a GPU-accelerated ML pipeline.

Problem

Lab analysts manually counted colonies on petrifilm plates across multiple test types — Aerobic Count, Yeast & Mold, E. coli, Coliform, Enterobacteria, Lactobacillus, B. cereus, and others. Manual counts were slow, error-prone, and fundamentally limited in throughput.

Solution

Trained Vision Transformers combined with CLIP embedding models and custom PyTorch classifiers to accurately count colonies and handle edge cases like TNTC (Too Numerous To Count) plates. A mechanical imaging bot captures petrifilm images and sends them to the ML system via a FastAPI endpoint, which returns structured colony count reports in real time.

Impact

  • Accuracy: 90–100% across all petrifilm types
  • Throughput: 10,000+ samples/day vs. <1,000 manually
  • Infrastructure cost: <$200/month on AWS GPU — vs. a 20-person analyst team
  • Zero marginal cost at higher volumes — scales horizontally

Stack

Vision Transformers, CLIP, PyTorch, FastAPI, AWS GPU instances

LLM · NL-to-SQL · Data Analytics

Natural Language Analytics Platform for Internal Teams

02

Built a chat-based analytics system that lets non-technical teams — operations, sales, customer support, and analysts — query live databases and generate visualizations using plain English, with no SQL or coding required.

Problem

Business teams were dependent on developers or analysts to pull data from MongoDB and MySQL databases. Reporting cycles were slow, and teams lacked real-time visibility into their own operational metrics.

Solution

Integrated the Claude LLM API to accept natural language queries, generate the corresponding Python code and database queries, and execute them in a secure sandbox environment connected to production databases. Results — including interactive Plotly charts, tables, and JSON outputs — are rendered directly in the UI for the user to explore and export.

Impact

  • Any team member can self-serve data queries — no SQL knowledge needed
  • Eliminated bottleneck of routing every data request through engineering
  • Exports (charts, tables) plug directly into reports and presentations
  • Code execution runs in an isolated sandbox — no direct DB access exposure

Stack

Claude LLM API, Python, Plotly, MongoDB, MySQL, FastAPI, sandboxed execution environment

Document AI · NLP · Computer Vision

AI-Powered Document Data Extraction at Scale

03

Led the end-to-end development of an AI service for intelligent data extraction from logistics and trade documents — processing 50,000 documents per day with high field-level accuracy across 100+ structured data points.

Problem

Logistics operations required manual extraction of structured data from high-volume, varied document types — Bills of Lading, Arrival Notices, ISFs, Invoices, Packing Lists, and Customs documents. Manual extraction was a critical bottleneck in the data ingestion pipeline.

Solution

Built a multi-model AI pipeline combining Detectron2 for document layout detection, spaCy-based NER models for entity recognition, Google T5 for structured text understanding, and GPT-4 Vision for visually complex documents. Developed a unified API layer for organisation-wide access to all AI extraction services.

Impact

  • Extracts 100+ fields per document — ETA, ETD, Consignee, Shipper, Manufacturer, Port of Lading, Country of Origin, Invoice Number, and more
  • Processes 50,000 documents/day in production
  • Data ingestion pipeline latency reduced by 75%
  • Single-handedly built and maintained the API layer used across the organisation

Stack

Detectron2, spaCy, Google T5, GPT-4 Vision, Python, FastAPI

PII Redaction · OCR · Compliance

Automated PII Redaction System (DPDPA Compliant)

04

Built a document redaction application for CA firms and banking clients to automatically detect and redact personally identifiable information in compliance with India's Digital Personal Data Protection Act (DPDPA).

Problem

CA firms and banks handle large volumes of sensitive client documents containing PAN, Aadhaar, bank account details, GST numbers, signatures, and photographs. Manual redaction before sharing documents was time-consuming and prone to missed fields.

Solution

Built a FastAPI-backed web application where users upload documents that are then processed through an OCR pipeline followed by AI-based PII detection using Microsoft Presidio — an open-source framework for detecting, masking, and anonymising sensitive data across text, images, and structured data. Supports custom keyword-based redaction rules, document splitting, and merging.

Impact

  • Fully automated redaction of PAN, Aadhaar, bank info, GST, photos, and signatures
  • DPDPA-aligned workflow with audit-ready outputs
  • Custom keyword rules allow clients to extend redaction beyond standard PII
  • Non-technical users can operate the entire workflow via a simple UI

Stack

FastAPI, Microsoft Presidio, OCR, Python, HTML/CSS

Academic · Physics Simulation · ML

Predicting Membrane Stiffness from Droplet Dynamics using ML

B.Tech

Undergraduate research project combining physics simulation and machine learning to model and predict the mechanical properties of soft substrates from droplet behaviour.

Approach

Simulated droplet dynamics on soft substrates using COMSOL Multiphysics. Experimental data from the simulation was used to train and compare multiple supervised ML models — SVM, Random Forest, Gradient Boosting, and ANNs — to predict membrane stiffness with minimal physical testing.

Significance

Demonstrated that ML can serve as a surrogate for expensive physical experiments in materials science, with models learning the non-linear relationship between droplet shape dynamics and substrate mechanical properties.
